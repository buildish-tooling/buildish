# Buildish site development

Project documentation lives on the Buildish site:

- <https://buildish.org/components/site/>

Use the unreleased Website development documentation for the sibling workspace
layout, rendering responsibilities, local and container workflows, authoring
helpers, and current limitations.

From the repository root, run `make check`. Run `make serve-local` to preview
the assembled site with the host toolchain.
