Buildish is a family of independent tools for build engineers, CI maintainers,
and project contributors. Its components cover shared Gradle and Maven caches,
Gradle Wrapper bootstrapping without a checked-in JAR, multi-repository
documentation assembly, release automation, and the Buildish website.

No Buildish release has been published. Component `development/` documentation
describes unreleased behavior, and interfaces may change. Browse the
[components](/components/) to choose a tool, or visit the
[community](/community/) to contribute.
