# Security Policy

## Supported Versions

Buildish has not published a release yet. Security reports affecting the current
development branches are welcome.

## Reporting a Vulnerability

Do not open a public issue for a suspected vulnerability. Report it privately to
[security@buildish.org](mailto:security@buildish.org), including the affected
component, impact, and reproduction details where possible.

## Threat Model

The repository contains a development threat-model review aid in
[site/site/docs/threat-model.md](site/site/docs/threat-model.md). It records
proposed security boundaries, scope, trust assumptions, invariants, and triage
guidance, but has not yet been maintainer-ratified as canonical. It is context
for reviewers and automated tooling, not an authoritative severity, advisory,
or CVE decision. Unresolved, inferred, or proposed assumptions in the model
must not be used by themselves to reject a private report.
